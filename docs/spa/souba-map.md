# 相場｜価格×取引件数マップ

## 概要

- マレーシア不動産の相場を地図ベースで把握する中核画面
- 参考サイト `souba` と同様に、1 画面内でフィルタや表示単位を切り替えながら閲覧する
- 画面遷移を極力減らし、直感的に操作できる構成とする
- 日本のデータではなく、マレーシアの取引データをもとに表示する
- 初期対象データは `Condominium/Apartment` のみに限定する

## 画面構成

### URL構成

- パス: `/souba`
- 本画面は相場機能の中心画面として利用する
- ページは `pages/souba/index.vue` で表示する想定

### レイアウト

- レイアウト: サイト共通レイアウト
- ページタイトル: `マレーシア不動産相場マップ`
- ヘッダー: サイト共通ヘッダー
- メイン構成:
  - 上部: 画面タイトルと簡易説明
  - 左または上部: フィルタパネル
  - 中央: 地図
  - 下部または右: 集計サマリーと一覧

### 表示形式

- 地図を主役にした 1 画面構成
- フィルタ操作に応じて、地図、集計サマリー、一覧データが同時に切り替わる
- 参考サイトのように「ポチポチ操作してデータを見比べる」体験を優先する
- 公開画面では `Property Type` フィルタを表示しない

### 参考デザイン方針

- デザインと操作感は [参考サイト `souba`](https://city-development-research.vercel.app/souba) にできるだけ近づける
- 「地図が主役」であることを最優先とする
- 1画面の中で情報が切り替わる体験を維持する
- 複雑な画面遷移よりも、現在地のまま比較できる導線を優先する

### レイアウト方針

- 画面中央または右側に大きく地図を配置する
- フィルタ・集計・一覧は地図を邪魔しないサイズ感でまとめる
- デスクトップでは「地図 + 情報パネル」の2カラム構成を基本とする
- モバイルではフィルタと一覧を折りたたみ可能にし、地図表示面積を優先する

### ビジュアル方針

- 派手すぎる UI よりも、情報が読みやすく直感的な配色を優先する
- 地図上の価格帯表現は、ひと目で高低差が分かる色分けにする
- ポップアップや一覧カードは過剰装飾せず、視線移動が少なく済むようにする
- タイポグラフィは読みやすさ優先で、数値情報が見分けやすいことを重視する

### 操作感の方針

- フィルタ変更時はできるだけ待ち時間を感じさせない
- 地図、一覧、サマリーの連動を明確にする
- ユーザーが「今どの条件を見ているか」が迷子にならないようにする
- 参考サイトと同様に、軽く触って比較できる操作感を目指す

## 絞り込み項目

### 表示レベル（areaLevel）

- UI: セグメント切替またはタブ
- 選択肢:
  - `1`: 州
  - `2`: 郵便番号エリア
- 初期値: `1`
- 変更時に地図、集計サマリー、一覧を再取得する

### 州（stateName）

- UI: セレクトボックス
- 初期値: 未選択
- `GET /api/map/filters` の州一覧を利用する
- 選択時に地図、集計サマリー、一覧を再取得する

### 郵便番号エリア（postalCode）

- UI: セレクトボックス
- 初期値: 未選択
- 選択肢は `GET /api/map/filters` の結果を利用する
- 州選択後に絞り込まれた候補を表示する想定
- 選択時に地図、集計サマリー、一覧を再取得する

### Tenure

- UI: セレクトボックス
- 初期値: 未選択
- 選択肢は `GET /api/map/filters` の結果を利用する
- 選択時に地図、集計サマリー、一覧を再取得する

### 取引期間（from / to）

- UI: 年月の範囲指定
- 初期値: データ全体の期間
- 変更時に地図、集計サマリー、一覧を再取得する

### 価格帯表示モード（priceBandMode）

- UI: セレクトまたはトグル
- 初期値: `default`
- 変更時に地図上の色分け基準のみ更新する

## 表示要素

### 地図エリア

- `areas.area_level` に応じて表示対象を切り替える
- 表示レベル:
  - `level_1`: 州
  - `level_2`: 郵便番号エリア
- 各エリアは代表緯度経度を中心に表示する
- 色やサイズで価格帯や件数を表現する
- 初期実装では「件数」と「平均価格」が直感的に分かることを優先する

### 集計サマリー

- 現在の条件における集計結果を表示する
- 表示候補:
  - 対象取引件数
  - 平均価格
  - 平均単価
  - 対象エリア数

### 一覧エリア

- 地図だけでは比較しづらい場合に備えて、同条件の一覧を表示する
- 地図と連動して表示内容を更新する
- 表示項目:
  - エリア名
  - 取引件数
  - 平均価格
  - 平均単価
  - 取引があった年数
  - 平均面積

## 地図上の表示仕様

### エリア表示

- 価格帯は段階分けして表示する
- 初期実装では連続値よりも、直感的に把握しやすい価格帯レンジ表示を優先する
- マーカーまたは円表示を基本とし、将来的にポリゴン表示も検討可能とする

### ポップアップ表示

- マーカーまたはエリア選択時にポップアップを表示する
- 表示項目:
  - エリア名
  - 表示レベル
  - 取引件数
  - 取引があった年数
  - 大きさ
  - 平均価格
  - 平均単価
- 完成年は取引データから直接は取得せず、物件マスターから参照可能な補助値として扱う
- 初期フェーズでは平均完成年を主表示には含めない

## 操作・機能

### データ取得

- 画面表示時（onMounted 相当）に以下を取得する
  - `GET /api/map/filters`
  - `GET /api/map/areas`
  - `GET /api/map/area-list`
- 初回表示条件:
  - `areaLevel = 1`
  - `stateName = null`
  - `postalCode = null`
  - `tenure = null`
  - `priceBandMode = default`

### 初期表示

- 初回表示時はマレーシア全体の相場を表示する
- 初期表示レベルは最も大きいエリア単位である `level_1` を基本とする
- 初期状態では広域比較ができることを優先する
- 初期状態の価格表示は価格帯レンジ分け表示とする

### フィルタ変更

- フィルタ変更時は画面遷移せず、現在画面内のデータのみを更新する
- 地図、サマリー、一覧は同時に再描画する
- 変更時は現在の条件を state に保持する

### 表示レベル変更

- `level_1`、`level_2` を UI から切り替え可能にする
- 将来的にはズーム連動切り替えも検討可能とする

### 地図選択

- 地図上のエリア選択時、そのエリアを中心とした詳細比較状態へ切り替える
- 必要に応じて一覧やサマリーの条件にも反映する
- クリックしたエリア ID を選択状態として保持する

## 技術仕様

### 想定ファイル構成

- ページ: `pages/souba/index.vue`
- 地図コンポーネント: `components/souba/SoubaMapCanvas.vue`
- フィルタコンポーネント: `components/souba/SoubaMapFilters.vue`
- 集計サマリー: `components/souba/SoubaMapSummary.vue`
- 一覧: `components/souba/SoubaAreaList.vue`
- コンポーザブル: `composables/useSoubaMap.ts`

### API

- 地図データ取得: `GET /api/map/areas`
- 一覧データ取得: `GET /api/map/area-list`
- フィルタ取得: `GET /api/map/filters`
- エリア詳細取得: `GET /api/areas/:id`

### 状態管理

- `areaLevel`
- `stateName`
- `postalCode`
- `tenure`
- `from`
- `to`
- `priceBandMode`
- `selectedAreaId`
- `mapAreas`
- `areaList`
- `summary`
- `filterOptions`

### エラー時の扱い

- API 取得失敗時は地図領域または一覧領域にエラーメッセージを表示する
- フィルタ取得に失敗した場合は再読み込み導線を表示する
- 地図データ取得失敗時は空表示とし、他 UI は極力維持する

## 備考

- 初期リリースでは日本語のみ表示
- 将来的な i18n 対応を見据え、表示文言は外出し可能な構造にする
- 参考サイトと同じく、分析メニューを増やすとしても、この画面の操作感はできるだけ維持する
