# 管理｜管理者管理

## 概要

- 管理者アカウントを管理する画面
- 初期フェーズでは最小限の一覧・追加・編集を想定する

## 画面構成

### URL構成

- パス: `/admin/admins`

## 表示項目

- 名前
- メールアドレス
- 権限レベル
- 状態

## 操作・機能

- 一覧表示
- 管理者アカウント追加
- 編集画面への遷移

### 管理者アカウント追加

- 本画面上または本画面から遷移する追加導線で、管理者アカウントを追加できるようにする
- 初期入力項目
  - 名前
  - メールアドレス
  - パスワード

## 備考

- 初期フェーズでは管理者作成時の最小入力を `名前` `メールアドレス` `パスワード` とする
- 詳細属性は後続で編集可能な前提とする

- 初期フェーズでは詳細な監査機能までは対象外とする
