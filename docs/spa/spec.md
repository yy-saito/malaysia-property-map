# SPA 設計書

## 概要

本ドキュメントは、マレーシア不動産マップの SPA 設計書です。参考サイト `souba` のように、相場観を地図とデータで把握できる構成を目指します。

## 設計方針

- Nuxt 4 を採用する
- テンプレートは Pug を利用する
- 初期リリースは日本語のみ
- ただし i18n 前提で文言管理する
- 地図とフィルタを中心に据えた UI とする
- 初期フェーズでは会員登録なしでも全画面へアクセス可能とする
- 将来的には会員レベルに応じた画面・機能制御を追加できるようにする

## 画面構成

### 1. 相場トップ

- パス: `/`
- 役割: サイトの導線トップ
- 表示内容:
  - サービス概要
  - 主要機能へのリンク
  - 相場マップへの導線

### 2. 価格 × 取引件数マップ

- パス: `/souba`
- 役割: 参考サイト `souba` に相当する中核画面
- 表示内容:
  - 地図
  - エリア色分け
  - 取引件数
  - 平均価格
  - フィルタ UI
 - 詳細仕様: [価格×取引件数マップ](./souba-map.md)

### 3. 物件タイプ別比較

- 別画面としては作成しない
- 必要な比較要素は `/souba` 画面内で表示を切り替えて扱う

### 4. CSV アップロード管理

- パス: `/admin/import`
- 役割: 管理用の CSV 取り込み画面
- 表示内容:
  - ファイルアップロード
  - 取込結果
  - 新規登録エリア確認

### 5. 管理画面

- 初期フェーズでは必要最小限の管理画面のみ提供する
- 対象画面
  - 物件情報一覧
  - 物件情報編集
  - CSV 取り込み
  - CSV 取り込み結果
  - 管理者管理
  - メンバー管理

## 主要な UI 要素

- 地図
- フィルタパネル
- 集計サマリーカード
- 一覧テーブル
- アップロードフォーム

## 文言管理方針

- 初期リリースでは日本語のみ
- ただし直書きを避け、i18n で管理可能な構造にする
- エリア説明や補足情報も将来的な多言語化を意識する

## 技術仕様

- フレームワーク: Nuxt 4
- テンプレート: Pug
- UI 基盤: Tailwind CSS
- 文言管理: i18n
- 現時点の対応言語: 日本語のみ
- バックエンド連携: Supabase + Edge Functions / RPC
- 地図ライブラリ: 未確定

## 認証・画面制御方針

- 初期リリースではログイン必須にしない
- 初期リリースでは全ユーザーが全画面を利用可能
- 将来的に会員レベルで表示制御できるよう、ルートメタやミドルウェアを追加可能な構造を想定する

### 想定会員レベル

- `guest`
- `member`
- `premium`
- `admin`
