# 管理｜物件情報編集

## 概要

- 管理者が物件情報を手動補完・修正する画面
- CSV に含まれない属性を補うための編集画面

## 画面構成

### URL構成

- パス: `/admin/properties/:id`

### レイアウト

- レイアウト: 管理画面共通レイアウト
- ページタイトル: `物件情報編集`

## 編集対象項目

- 物件名
- エリア
- Property Type
- developer
- 解決済み住所
- 郵便番号
- 完成年
- 補足説明

## 操作・機能

- 保存
- 一覧へ戻る
- 変更前後の確認

## 備考

- 初期フェーズでは削除機能は必須としない
- 完成年と物件ノートは手動補完対象として本画面で編集可能にする
