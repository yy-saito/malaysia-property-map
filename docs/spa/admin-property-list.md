# 管理｜物件情報一覧

## 概要

- 管理者が物件情報を一覧で確認する画面
- CSV 取込後の物件データ確認と、手動補完対象の確認に利用する
- 一覧から編集画面へ遷移する

## 画面構成

### URL構成

- パス: `/admin/properties`

### レイアウト

- レイアウト: 管理画面共通レイアウト
- ページタイトル: `物件情報一覧`

### 表示形式

- 一覧テーブル形式
- 最小限の検索・絞り込みのみ提供する

## 表示項目

- 物件名
- エリア名
- Property Type
- developer
- 完成年
- 補足情報有無
- 更新日時

## 操作・機能

- 行クリックで編集画面へ遷移
- 物件名、エリア、Property Type で絞り込み可能
- 完成年未設定などの未補完条件で絞り込み可能

## 技術仕様

- 一覧取得 API を利用する
- 初期フェーズではシンプルなページネーションまたは件数制御で対応する
